Inventory Analysis Tool

Overview
A Python - based inventory analysis tool that ready inventory data from a CSV file and identifies common data quality issues.

Features:
Load inventory data using pandas
Detects missing values
Identifies duplicate SKU records
Flag negative inventory quantities
Generates a summary report

Tech. Used:
Python
Pandas
CSV File Processing

Project Structure:
inventory_project/
inventory.csv
inventory_analysis.py
requirements.txt

How to Run
Install dependencies:
pip install -r requirements.txt

Run the analysis:
python inventory_analysis.py

Purpose:
This project demeonstrated data analysis, data validation, and inventory reporting using Pthong and Pandas.
